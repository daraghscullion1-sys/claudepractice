## Container Request Workflow

When a user writes **"Container Request"**, Claude will:

1. Ask the user for the **Container Title**
2. Draft a professional and friendly email to send to the relevant person to get the container set up

### Example Interaction

**User:** Container Request

**Claude:** Sure! What would you like to name the container? Please provide the **Container Title** and I'll draft an email for you.

**User:** Data Processing Pipeline

**Claude:**

---

**Subject:** Container Setup Request — Data Processing Pipeline

Hi [Name],

I hope you're doing well! I'm reaching out to request the setup of a new container for our team.

**Container Title:** Data Processing Pipeline

Could you please assist with getting this configured at your earliest convenience? If you need any additional details or have any questions, don't hesitate to reach out — happy to help with whatever is needed.

Thank you so much for your time and support, it's really appreciated!

Best regards,
[Your Name]
